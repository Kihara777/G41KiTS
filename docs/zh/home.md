# home
中文 | [English](../en/home.md) | [日本語](../ja/home.md)

站点核心数据 — 角色消息、主题色、状态码、i18n。模块直接提供 homete 磁贴（G41KiTS 项目介绍）。

## 基本信息

| 项目 | 值 |
|------|-----|
| 类型 | data + tile |
| 依赖 | core, nginx, redis |
| compose | none |

## 提供内容

- **磁贴**：tile_homete（G41KiTS 项目概览与技术栈）
- **全局 i18n**：角色对话、问候语 — JA / ZH / EN
- **数据文件**：chars.json、colors.json、langs.json、status.json
- **Web 资源**：首页 HTML、JS、CSS、图片
- **站点配置**：SSL/TLS 基础设置、HSTS、错误页（prefix=0）

## 安装

```bash
./g41.sh kits add home
```

## 首屏加载（启动环与失败态）

首屏要等 `G41.js` 的六个数据请求（tiles / chars / status / 三语 i18n）全部到齐才 `init()`，
`#g41-app` 在此之前是 `opacity:0`。这段空白期由 `#g41-loading` 的 **WP8 启动环**填充。

**为什么样式内联在 `G41.html` 里**：三份 `.css`（约 15KB）曾是渲染阻塞的——HTML 到了也只是白屏，
第一个像素要等样式表回来。本地用桩把样式表延迟 3 秒实测：首次绘制
**3024 / 6908ms →（内联后）36 / 928ms**，`performance` 里 `/css/` 请求数变成 0。
**首屏只有一个请求（HTML 自己）**，环在首字节即可绘制。样式就改 `G41.html` 的 `<style>`
（仓库里不再有独立 `.css` 源文件，避免两份漂移）。

**几何与颜色**：环直径与点径按 `vmin` 缩放（手机约 99px / 9px），五点在圆周上等距（72°），
**点径固定**；颜色取 `--wp-amber`，底为**不透明黑**（WP8 启动画面本是纯色，也避免立绘抢视线）；
环下有一行**可见**的「読み込み中 / Loading」（i18n 尚未读到，故为静态二语言）。

**动画是三个阶段的循环**（3.2s）：

| 阶段 | 实现 | 判据（一个周期的采样） |
|------|------|------------------------|
| 进场 | 每点只做透明度的浮现，五点错开 0.12s | 可见点数 `0 → 1 → 2 → 3 → 4 → 5` |
| 旋转 | 整个环匀速旋转，`cubic-bezier(.55,.05,.45,.95)` 让快慢有致 | 整环角度单调推进 |
| 退场 | 同样的错峰熄灭 | 可见点数 `5 → 4 → … → 0`，随后约 0.36s 空档再开始下一轮 |

点径与位置都不随动画变化（只有 `opacity` 在变），所以「点大小固定」是可量的：
五点 `::after` 的计算宽度实测全等。`prefers-reduced-motion` 下两个动画都关掉——五点静止全亮。

| 状态 | 谁来切 | 表现 |
|------|--------|------|
| 启动中 | 无需 JS | 琥珀色 5 点环（视口居中） |
| 就绪 | `applyStatus()` 里的 `revealApp()` | **先**收环（淡出），**再**在 `requestAnimationFrame` 里给主视图加入场动画并淡入——顺序见下 |
| 启动失败 | `bootFailed()` | 环换成「読み込みに失敗しました / Failed to load」+ 错误原文 |

**收环时机是判据**：`main-entry` 原先在 `init()` 里就加上，入场动画会在 `opacity:0` 的幕后播完，
环收掉时看到的是静止的成品。现在实测时序是
`ring 1 →（0.28 且 entry:true、tiles:12）→ app 1 → 环移除`——磁贴就绪与入场动画同帧、环同时开始淡出。

**环不能一直转**：一直转等于在说「还在读」。`bootFailed()` 存在的理由就是它。

（四轮修订的来龙去脉见 `MAINTENANCE.md` 2026-10-12 条目。）

### 脚本顺序是判据，不是风格

```html
<script src="/js/tiles.js"></script>   <!-- 必须先执行：closeDetail / buildTiles 在这里 -->
<script src="/js/G41.js"></script>     <!-- 一执行就发起数据请求，回调里要用上面那些函数 -->
```

反过来的话，冷启动（无缓存）时数据可能先回来，`init()` 抛 `ReferenceError: closeDetail is not defined`
→ 整页停在 `opacity:0`。**2026-10-12 实测：修复前冷启动 5/5 白屏**；
把 `tiles.js` 延迟 3 秒可在本地确定性复现。`tiles.js` 顶层只有函数声明、不依赖 `G41.js`，
所以放在前面是安全的。
