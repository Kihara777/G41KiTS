# home
中文 | [English](../en/home.md) | [日本語](../ja/home.md)

站点核心数据 — 角色消息、主题色、状态码、i18n。模块直接提供 homete 磁贴（G41KiTS 项目介绍）。

## 基本信息

| 项目 | 值 |
|------|-----|
| 类型 | data + tile |
| 依赖 | core, nginx, redis |
| compose | none |

## 提供内容

- **磁贴**：tile_homete（G41KiTS 项目概览与技术栈）
- **全局 i18n**：角色对话、问候语 — JA / ZH / EN
- **数据文件**：chars.json、colors.json、langs.json、status.json
- **Web 资源**：首页 HTML、JS、CSS、图片
- **站点配置**：SSL/TLS 基础设置、HSTS、错误页（prefix=0）

## 安装

```bash
./g41.sh kits add home
```

## 首屏加载（启动环与失败态）

首屏要等 `G41.js` 的六个数据请求（tiles / chars / status / 三语 i18n）全部到齐才 `init()`，
`#g41-app` 在此之前是 `opacity:0`。这段空白期由 `#g41-loading` 的 **WP8 启动环**填充：
纯 CSS（`base.css` 的 `.g41-ring`），JS 到达前的第一帧就能显示；
`prefers-reduced-motion` 下退化为**静止的 5 点**。

**第二版（2026-10-12）**：第一版只有一个 64px 的环（6px 点），维护者在手机上反馈
「没有出现或者不够明显」——实测量到它在 412×915 下直径只占屏宽 15%、点占 1.4%。
现在三处加强：直径/点径按 `vmin` 缩放（手机约 99px / 9px）、环下加一行**可见**的
「読み込み中 / Loading」、整体压一层 `rgba(0,0,0,.55)` 暗幕（否则全屏立绘会把环吃掉）。

**第三版（2026-10-12，同日再反馈）**：她指出三点，两条是判据性的：

1. **五点要成一条链**。旧实现每个点各自跑完整条 keyframes（含各自的停顿），相位只保证均匀分布、
   不保证顺序——实测同一时刻相邻间隔 96°/282°/81°/147°/114°，两颗还几乎重叠。
   现在五点共用同一条旋转曲线（2.4s / `cubic-bezier(.5,.08,.5,.92)`），只用负延迟错开相位：
   顺序永不乱，缓动让弧长自然呼吸；点径 100/85/70/55/42% 形成彗尾。实测内部间隔 38–44°、
   两次采样均单调有序。点中心按半径补偿（`top = (dot − size)/2`），大小不一的点仍落在同一个圆上。
2. **收环的时机**：`main-entry` 原先在 `init()` 里就加上，入场动画会在 `opacity:0` 的幕后播完，
   环收掉时看到的是静止的成品。现在移到 `revealApp()`：先收环，再在 `requestAnimationFrame`
   里加入场动画并淡入。实测时序 `ring 1 →（0.28 且 entry:true、tiles:12）→ app 1 → 环移除`。
3. **加载期间不显示背景**：覆盖层由半透明暗幕改成**不透明黑**（WP8 启动画面本就是纯色），
   立绘抢视线的问题消失，失败态文案的对比度也更好。

| 状态 | 谁来切 | 表现 |
|------|--------|------|
| 启动中 | 无需 JS | 琥珀色 5 点环（视口居中） |
| 就绪 | `applyStatus()` 里的 `endLoading()` | 环淡出，`#g41-app` 淡入（成功页与状态码页都走到） |
| 启动失败 | `bootFailed()` | 环换成「読み込みに失敗しました / Failed to load」+ 错误原文 |

**环不能一直转**：一直转等于在说「还在读」。`bootFailed()` 存在的理由就是它。

### 脚本顺序是判据，不是风格

```html
<script src="/js/tiles.js"></script>   <!-- 必须先执行：closeDetail / buildTiles 在这里 -->
<script src="/js/G41.js"></script>     <!-- 一执行就发起数据请求，回调里要用上面那些函数 -->
```

反过来的话，冷启动（无缓存）时数据可能先回来，`init()` 抛 `ReferenceError: closeDetail is not defined`
→ 整页停在 `opacity:0`。**2026-10-12 实测：修复前冷启动 5/5 白屏**；
把 `tiles.js` 延迟 3 秒可在本地确定性复现。`tiles.js` 顶层只有函数声明、不依赖 `G41.js`，
所以放在前面是安全的。
